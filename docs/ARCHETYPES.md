# Cube archetypes

The archetype list the card tags are built from. Ari's primer archetypes first, then ones proposed from
reading the cube (marked **proposed**), then the combos. Edit freely: this file is the source of truth,
the tags follow it.

Each card gets one or more tags, each with a role:
- **P** payoff: the card the deck is built around (Sneak Attack, Tolarian Academy, Thopter Foundry).
- **E** enabler: makes the payoff work (Entomb, Dark Ritual, Goblin Welder).
- **F** fits: a good card for the deck that doesn't define it (Lightning Bolt in aggro, Counterspell in control).

Counts below are from the 547-card list on 2026-11-01 and are rough: they're what the tagging pass will make exact.
